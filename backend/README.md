# TerraSharp Atlas — FastAPI Backend

A runnable Python backend that implements the same API the frontend expects
(see [`../FASTAPI_CONTRACT.md`](../FASTAPI_CONTRACT.md)), **plus** the PDF report
endpoints used by the Export buttons. PDFs are generated by a small
dependency-free writer (`app/pdf.py`) — no reportlab or other native library.

> The Next.js app already ships working mock routes under `frontend/src/app/api/*`,
> so the demo runs standalone. This backend is for running the platform against a
> real Python service.

## Run

```bash
cd backend
python -m venv .venv && .venv\Scripts\activate      # Windows
# source .venv/bin/activate                          # macOS/Linux
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Interactive docs: <http://localhost:8000/docs>

Point the frontend at it — create `frontend/.env.local`:

```
NEXT_PUBLIC_API_BASE_URL=http://localhost:8000
```

then restart `npm run dev`. No frontend code changes are needed.

## Endpoints

| Method | Path                              | Returns              |
| ------ | --------------------------------- | -------------------- |
| GET    | `/api/dashboard`                  | dashboard JSON       |
| GET    | `/api/queue`                      | queue JSON (filters) |
| GET    | `/api/projects`                   | projects JSON        |
| GET    | `/api/comparison/{job_id}`        | comparison JSON      |
| GET    | `/api/validation/{job_id}`        | validation JSON      |
| GET/PUT| `/api/settings`                   | settings JSON        |
| POST   | `/api/jobs`                       | `{job_id, status}`   |
| POST   | `/api/jobs/estimate`              | estimate JSON        |
| GET    | `/api/reports/validation/{job_id}`| **application/pdf**  |
| GET    | `/api/reports/comparison/{job_id}`| **application/pdf**  |
| GET    | `/api/reports/job/{job_id}`       | **application/pdf**  |
| GET    | `/api/reports/invoice/{id}`       | **application/pdf**  |

## Tests

No server or extra dependencies required:

```bash
cd backend
python -m unittest discover -s tests
```
